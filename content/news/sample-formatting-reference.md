*This is a sample post created to show how the News section renders. It should be deleted before launch.*

Ordinary paragraphs read at a comfortable measure and set in the firm's serif. Everything below is available from the toolbar in the editor — nothing requires writing in code.

## A second-level heading

Headings break a longer post into sections and appear in the order written. A third level is available beneath this one where a post needs it.

### A third-level heading

Emphasis is available as *italic* and **bold**, and lists set as expected:

- A bulleted item
- A second item
- A third item

> A block quote is set off by an oxblood rule and reads in gray — the treatment used for language quoted from an opinion or a filing.

Links to an [external filing or opinion](https://www.example.com) are underlined, and turn oxblood on hover. Footnotes carry a citation without breaking the sentence.[^1]

[^1]: The footnote text appears here, numbered automatically, with a link back to where it was referenced.
